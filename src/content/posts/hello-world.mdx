# Welcome to The Brain

This is my **Digital Garden**. It's different from a traditional blog. Instead of highly polished, chronological posts, a digital garden is a living web of thoughts, notes, and technical deep-dives that grow over time.

## Why a Digital Garden?

As a software engineer, I constantly learn new things—from distributed systems architectures to micro-optimizations in C++. Writing things down helps me solidify my understanding, but traditional blogs feel too rigid. 

Here, I can:
1. Plant "seeds" (rough ideas or code snippets).
2. Cultivate them into "saplings" (drafts and tutorials).
3. Grow them into "trees" (comprehensive guides).

## Interactive Code

Since this is powered by **MDX**, I can write standard Markdown but also render interactive React components right in the middle of a post.
